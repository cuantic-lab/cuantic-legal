Política de privacidad

Cuantic Windows · Moderación de comentarios de Instagram

Esta política explica qué datos usa nuestra aplicación y para qué. Última actualización: 21 de octubre de 2026.

Qué hace la aplicación

La aplicación "Cuantic Windows Moderación" se conecta a nuestra propia cuenta profesional de Instagram (@lamentecuantica_es) mediante la API oficial de Instagram. Lee los comentarios de nuestras publicaciones para ocultar spam, responder con amabilidad y mantener sana la conversación.

Qué datos tratamos

Texto, nombre de usuario y fecha de los comentarios públicos que se publican en nuestras propias publicaciones. No accedemos a mensajes directos, contactos, ubicación ni datos de otras cuentas.

Cómo los usamos

Solo para moderar los comentarios de nuestra cuenta: detectar spam, ocultarlo y redactar respuestas. No vendemos, compartimos ni cedemos estos datos a terceros, y no los usamos para publicidad ni para perfilar personas.

Conservación y seguridad

Guardamos únicamente el identificador de cada comentario ya procesado, el tiempo mínimo necesario para no repetir acciones. Las credenciales de acceso se almacenan en un sistema seguro y no se publican.

Tus derechos

Podés pedirnos que eliminemos cualquier dato asociado a un comentario tuyo. Mirá las instrucciones en la página de eliminación de datos o escribinos.
